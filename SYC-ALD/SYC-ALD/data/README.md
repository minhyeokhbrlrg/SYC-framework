# Input data

Put the input geometries here (formats are described in the main README):

| File (as used in `config/example_trust_on_ru.json`) | Content |
|---|---|
| `TRuST_gas.csv` | Gas-phase Ru(TMM)(CO)₃ geometry (`name,1,2,3`) |
| `TRuST_chemisorbed_template.csv` | Chemisorbed geometry relative to the surface Ru on-site at (0, 0, 0) |
| `Ru_substrate.csv` | Ru unit cell with two `lattice` rows |
